# Delegates

Ein Visual-Studio-Projekt zur Einführung in die Verwendung von Delegates und deren Einsatz in der .NET-Programmierung.

## Beschreibung

Das Projekt **Delegates** beschäftigt sich mit den Grundlagen der Verwendung von Delegates in C#. Delegates ermöglichen es, Methoden als Referenzen zu speichern, an andere Methoden zu übergeben und dynamisch aufzurufen.

Im Mittelpunkt stehen die Definition und Verwendung von Delegates sowie die flexible Steuerung von Methodenaufrufen innerhalb einer Anwendung.

## Funktionen

- Definition und Verwendung von Delegates
- Referenzierung und Aufruf von Methoden
- Übergabe von Methoden als Parameter
- Dynamische Ausführung unterschiedlicher Methoden
- Grundlagen der ereignisgesteuerten Programmierung
- Einführung in typsichere Methodenreferenzen

## Technologien

- Microsoft Visual Studio
- C# / .NET
- Visual-Studio-Projektmappe (.sln)

## Installation und Ausführung

1. Repository klonen:

   ```bash
   git clone https://github.com/samad-pour/Delegates.git
   ```

2. Die Datei `Delegates.sln` in Visual Studio öffnen.
3. Das Projekt erstellen.
4. Die Anwendung mit `F5` starten.
